# OURPROCESSORSELF v0.8: Sovereign Runtime Substrate

## Constitutional boundary

The host is substrate. It is not processor identity or constitutional authority.

```
HOST = substrate
INSTANCE = bounded execution identity/state
CONSTITUTION = governance
PROCESSOR = transformation
ACTUATOR = causal boundary
WITNESS = evidence production
SELFGRAPH = modeled reality
```

The v0.8 invariants are:

```
HOST != INSTANCE
INSTANCE != PROCESSOR
PROCESSOR != AUTHORITY
AUTHORITY != ACTUATOR
ACTUATOR != WITNESS
WITNESS != REALITY
RECEIPT != EFFECT
EFFECT != OBSERVATION
OBSERVATION != VERIFICATION
```

## Six primitives

1. RUNTIME
2. INSTANCE
3. ADAPTER
4. ACTUATOR
5. WITNESS
6. CONTINUATION

A runtime hosts an instance. An instance binds constitution, processor identity,
authority semantics, SELFGRAPH, capabilities, and actuator identities.

Adapters translate external surfaces into admission-compatible operations.
Actuators cross the causal boundary. Witnesses must observe resulting state
through a read-back path rather than trusting an execution receipt.

## Boot contract

```
BLANK SUBSTRATE
  -> BOOT INSTANCE
  -> BIND CONSTITUTION
  -> BIND PROCESSOR
  -> BIND SELFGRAPH
  -> BIND AUTHORITY
  -> BIND CAPABILITIES
  -> BIND ACTUATORS
  -> ESTABLISH WITNESS
  -> VERIFY PRECONDITIONS
  -> HOT LOOP
```

## Sovereignty property

GitHub Actions is an optional external execution surface. It is not a
constitutional dependency of OURPROCESSORSELF.

The sovereign runtime must be able to continue when an external CI provider
is unavailable, disabled, rate-limited, or billing-blocked.

## Host substitution test

For a valid instance I, changing only the host may change runtime and adapter
implementation and available capabilities. It must not silently change:

- processor identity
- constitution
- authority semantics
- SELFGRAPH semantics
- causal lineage semantics
- witness semantics

A capability failure means:

```
"I cannot perform this transition on this substrate."
```

It must never silently become:

```
"My constitutional identity has changed."
```

## Acceptance target

The same instance contract must execute bounded transitions on heterogeneous
substrates while preserving its semantic identity. GitHub Actions may witness
the project, but the processor must not depend on it for existence or
continuation.
