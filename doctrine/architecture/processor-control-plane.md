# OURPROCESSORSELF Control-Plane Doctrine

## Constitutional boundaries

EVENT != AUTHORITY
GIT != RUNTIME
AGENT != ACTUATOR
RECEIPT != EFFECT
OBSERVATION != ADMISSION

## Hot loop

EVENT -> FETCH -> NORMALIZE -> CLASSIFY -> SEMANTIC OBJECT -> POLICY -> ADMISSION -> PROGRAM -> PROCESSOR -> STATE/EFFECT -> OBSERVATION -> RECEIPT

## Cold loop

RECEIPT -> EVIDENCE -> INSTANCE -> ANALYSIS -> PROPOSED MUTATION -> PRESSURE TEST -> POLICY -> ADMISSION -> SOURCE MUTATION -> NEW ARTIFACT -> NEW PROCESSOR REALITY

## Admission

Admission means the transition is permitted to enter execution. It does not guarantee execution success or effect.

## Processor function

P : (I, S, A, C, B) -> (S', R)

I = instruction/input
S = pre-state
A = authority state
C = capability state
B = execution bounds
S' = resulting state
R = receipt
